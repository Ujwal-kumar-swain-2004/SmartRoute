# Repository contents

Source code, tests, build/start scripts, documentation and the attributed OSM road extract are included.

API credentials, local environment files, dependency folders, generated frontend assets and Java build outputs are excluded. Set `TOMTOM_API_KEY` in the terminal that starts the backend; no provider key should be committed.

The collected BhubaneswarOne transit GeoJSON/CSV snapshots and CRUT map PDF remain local because their redistribution terms were not confirmed in the source metadata. The source register, collection manifest, provenance guide and bounded collection script are included so the datasets can be requested or recreated locally. This exclusion does not delete the local collected files.

OSM attribution and dataset provenance: `data/README.md`.
Transit source/access details: `data/transit/README.md`.
